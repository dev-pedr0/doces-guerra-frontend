# Doces Guerra - Frontend

Este é o repositório frontend do projeto "Doces Guerra", construído com base em um design do Figma. Este documento e os arquivos de documentação auxiliares servem como guia estrito para o desenvolvimento, arquitetura e estilização do projeto.

## Tecnologias e Versões Estritas

É mandatório o uso **exato** das seguintes versões para garantir a compatibilidade do projeto:

*   **Node.js:** 24.19.0
*   **Next.js:** 16.3.4
*   **React:** 19.2.8
*   **React DOM:** 19.2.8
*   **TailwindCSS:** 4.3.3
*   **TypeScript:** 5.9.3

## Documentação do Projeto

Para entender as regras e padrões arquiteturais deste projeto, consulte os arquivos abaixo antes de iniciar qualquer desenvolvimento:

*   [`project-structure.md`](./project-structure.md): Regras de organização de pastas e arquivos.
*   [`style-patterns.md`](./style-patterns.md): Sistema de design, cores, tipografia e regras de TailwindCSS.
*   [`AGENTS.md`](./AGENTS.md): Instruções vitais para assistentes de IA que operam neste repositório.

*Nota: Este repositório receberá futuramente documentações adicionais sobre componentes, estrutura de páginas e fluxos.*
